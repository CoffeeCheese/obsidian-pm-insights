# Project Manager Insights 0.6.2

[English](./0.6.2.md)

Project Manager Insights 0.6.2 在个人交付简报中新增 **今日完成**任务列表。

## 功能亮点

- 宽窗口下，在交付窗口和工作负载旁查看今日完成数量及时间线；窄窗口下，时间线移到规划内容下方。
- 每项记录展示完成时刻、任务标题和所属项目，点击可在 Project Manager 中打开源任务。长标题会换行，不再遮挡列表说明。
- 按设备本地日期和时区解释原生 `completed` 字段。只有日期、没有具体时刻的记录标为 **仅日期**，排在有时刻的记录之后。仅有已完成状态、没有可用完成日期的任务不计入今日数量；空状态会说明原因。
- 列表遵循当前成员、所选项目、归档和父任务设置及成员别名；共享任务在每位相关成员的列表中各出现一次。任务数据变化后，已打开的简报会刷新；跨过本地午夜会切换到新的一天。

## 升级说明

无需迁移或新增设置。本功能只读取 Project Manager 现有的任务完成字段，不修改任务笔记。交付规划范围不会限制今日完成列表。本插件最低 Obsidian 版本仍为 1.7.2。

## 验证

- TypeScript 类型检查、Obsidian ESLint、官方审核检查、全部 215 项自动化测试及生产构建通过。
- 在 dev-test 库验证了原生完成日期、任务打开、实时刷新、本地午夜切换、键盘操作以及窄窗口和长标题布局；临时原生任务样本已清理。
