# Project Manager Insights 0.5.2

[简体中文](./0.5.2.zh-CN.md)

Project Manager Insights 0.5.2 adds owner-bottleneck capacity planning to the final launch reminder and fixes accidental date selection while navigating months in the delivery-gate calendar.

## Highlights

- Compare each owner's remaining effort with personal capacity at every effective stage gate and the launch date instead of treating the whole team as one serial resource.
- Keep different owners parallel, accumulate one person's unfinished work across stages, resolve member aliases before grouping, and split shared-task effort evenly among assignees.
- Surface total remaining effort, the bottleneck owner, bottleneck load, shortfall or buffer, parallel owner lanes, and an expandable capacity breakdown for every checkpoint.
- Keep the launch reminder collapsed by default; opening it reveals the owner-capacity section with an explicit expand/collapse control and responsive layouts for narrower panels.
- Configure hours per person separately for workdays and calendar days under **Settings → PM Insights → Gate risk rules**. Both default to eight hours.

## Fixes

- Navigating to the previous or next month in a native delivery-gate date picker no longer selects a provisional date, closes the calendar, or rerenders the editor.
- A date is now committed only after the user confirms a change, while normal date selection and launch-date recording continue to work.

## Compatibility and upgrade notes

- Existing settings are normalized automatically with eight-hour workday and calendar-day capacity defaults; no manual migration is required.
- Direct task-detail opening continues to support Project Manager `1.8.x` and `2.1.x`.
- Obsidian `1.7.2` or later remains supported.
- PM Insights remains read-only for Project Manager project and task notes.

## Verification

- TypeScript checking, Obsidian ESLint rules, and official-review regression checks pass.
- All 110 automated tests pass across 14 test files, including owner-capacity aggregation and settings-compatibility coverage.
- Real `dev-test` Vault checks confirm that calendar month navigation stays open until a date is confirmed and that the launch reminder exposes the expected owner-capacity checkpoints.
- The production bundle builds successfully.
