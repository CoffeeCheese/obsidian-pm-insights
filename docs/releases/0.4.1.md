# Project Manager Insights 0.4.1

[简体中文](./0.4.1.zh-CN.md)

Project Manager Insights 0.4.1 makes delivery progress easier to read against the configured Project Manager schedule. Each delivery stage now shows what progress was expected by today, how far actual progress differs from that target, and where the target sits on the progress rail.

## Highlights

### Expected progress beside every delivery stage

- Show the planned percentage and signed variance directly after the Development, Testing, and Acceptance stage labels, using a compact `expected% / ±variance%` format.
- Color positive, negative, and on-plan variance states so schedule position can be scanned without adding verbose labels.
- Keep the actual completion percentage aligned separately at the edge of each card.

### Schedule targets grounded in Project Manager data

- Derive each expected percentage from the delivery-gate schedule already configured for the relevant Project Manager projects.
- Aggregate cross-project targets using the work represented by each project: stage task counts for Development and Testing, and root-task counts for Acceptance.
- Withhold a partial comparison when any relevant project has no applicable gate schedule, avoiding a misleading aggregate.

### Clearer progress rails and details

- Add an expected-progress marker to each stage rail so actual and planned positions can be compared visually.
- Provide a compact custom tooltip with separate Expected and Variance values on pointer hover or keyboard focus.
- Use `%` consistently in the compact display and tooltip, including signed values such as `+44.4%`, `−8%`, and `±0%`.
- Explain unavailable or unconfigured comparisons without crowding the default stage-card layout.

### Polished interaction and documentation

- Remove the unrelated default “Delivery progress” tooltip that appeared when hovering over the complete delivery section, while preserving its accessible region name.
- Improve stage-card spacing and responsive behavior so the added schedule context remains readable on narrow layouts.
- Refocus the English and Simplified Chinese README screenshots on the plugin UI and remove superseded image assets.

## Compatibility and upgrade notes

- Obsidian `1.7.2` or later remains supported.
- Project Manager remains required, and Project Manager Insights remains read-only.
- No project notes, task notes, Project Manager metadata, or configured gate schedules are modified by this upgrade.
- The plugin ID remains `project-manager-insights`.

## Verification

- TypeScript checking, Obsidian ESLint rules, and official-review regression checks pass.
- All 66 automated tests pass across 10 test files, including the new cross-project delivery-schedule comparison coverage.
- The production bundle builds successfully.

This release contains no breaking changes to Project Manager data or existing PM Insights settings.
