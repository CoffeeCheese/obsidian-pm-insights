# Project Manager Insights 0.3.1

[简体中文](https://github.com/CoffeeCheese/obsidian-pm-insights/blob/main/docs/releases/0.3.1.zh-CN.md)

Project Manager Insights 0.3.1 makes delivery health easier to inspect and act on. It adds configurable delivery gates, task-level issue drill-downs, and a clearer selected-project scope, while tightening acceptance and skipped-stage semantics.

## Highlights

### Configurable delivery gates and schedule risk

- Set a natural-day schedule for every configured delivery stage, the acceptance gate, and the final launch reminder of each selected project.
- Compare actual progress with the progress expected by each gate date, with clear normal, attention, high-risk, overdue, and passed states.
- Inspect the tasks behind a risk signal, including overdue tasks, work scheduled beyond a gate, missing due dates, missing estimates, missing assignees, and acceptance blockers.
- Keep stage risk scoped to that stage; acceptance and launch signals additionally account for acceptance blockers.
- Treat the final launch gate as a planning reminder. Delivery completion continues to be determined by acceptance progress.
- Preserve skipped-stage meaning: stages configured to skip empty work pass without being mislabeled as overdue or assigned an invented pass time.

### Actionable delivery issues

- Open the delivery-issue banner to see the exact tasks behind missing prerequisites and prematurely completed root tasks.
- Filter issues by category and open a task directly in Project Manager, then return to the issue dialog after closing the task editor.
- Choose whether completed root tasks should still be checked against prerequisite stages. Existing installations keep validation enabled until the setting is changed.
- Require real completion evidence for acceptance so moving a task into an in-progress acceptance lane does not count as accepted.

### Clearer project scope and dashboard controls

- See every selected project directly in the dashboard scope rail and remove a project with its compact close control.
- Hide or restore the delivery-progress section from the dashboard, with the preference persisted in settings.
- Refined reset, progress visibility, issue filter, dialog empty-state, hover, tooltip, and keyboard-focus interactions to stay compact and stable across modal transitions.

## Compatibility and upgrade notes

- Obsidian `1.7.2` or later remains supported.
- Project Manager remains required, and Project Manager Insights remains read-only.
- Gate schedules and the completed-root validation preference are stored in plugin settings; no project or task notes are modified.
- Existing delivery-progress settings are migrated automatically. Gate schedules remain unconfigured until users add dates for a project.
- The plugin ID remains `project-manager-insights`.
