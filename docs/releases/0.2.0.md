# Project Manager Insights 0.2.0

[简体中文](./0.2.0.zh-CN.md)

Project Manager Insights 0.2.0 turns the assignee detail panel into a more capable investigation workspace. This release adds personal delivery ratios, composable task filters, adjustable table columns, and direct Project Manager navigation while tightening the task-counting rules behind every total.

## Highlights

### Six personal ratios in three compact groups

The assignee header now summarizes six ratios without pushing the task list farther down the page:

- **Delivery:** task closure and planned work closed.
- **Time:** time consumed and tasks over budget.
- **Data foundation:** estimate accuracy and estimate coverage.

Ratios with no valid sample display an em dash instead of a misleading zero. The summary also adapts to narrow panes, including layouts where Obsidian's left sidebar is expanded.

### Project and status task filters

The assignee task panel now supports:

- Multi-select project filters built from the projects present in the current assignee's task list.
- Multi-select status filters built from the statuses present in the same list.
- Combined text, project, and status filtering.
- Clear-all, select-all, reset, click-outside dismissal, and `Escape` dismissal.

The visible-task counter makes the effect of the active filters explicit.

### Resizable, aligned task columns

Task table columns can now be resized with a pointer or keyboard. Double-clicking a divider restores the default widths. Headers and record values use the same left-aligned layout rules, and the task column remains usable when the rest of the table needs horizontal scrolling.

### Direct Project Manager navigation

- Select a task title to open that task directly in Project Manager's editor over the current Insights view.
- Select a project name to open the corresponding Project Manager project in a new Obsidian tab.
- Task titles and project names retain their original text presentation instead of appearing as raised buttons.

Direct task-editor opening is supported with Project Manager `1.8.x`. Project Manager Insights remains read-only; edits made in the task editor are handled by Project Manager.

## Statistics and data-quality changes

- Count included subtasks directly in the data-quality summary.
- Exclude root records explicitly marked as `type: task`, even when they currently have no subtasks.
- Continue inferring parent tasks from `parentId` relationships when type metadata is absent.
- Report unestimated, unassigned, and excluded parent-task counts alongside the included subtask total.

These rules prevent requirement-level or other parent tasks from being counted as executable subtasks simply because their child list is empty.

## Interaction and visual refinements

- Project menus now close naturally when focus moves outside them.
- Filter menus stay above draggable column handles and no longer expose stray divider lines.
- Member ratios occupy the unused space beside the assignee name instead of adding a large block between the header and task data.
- Narrow detail panels contain the ratio summary without overflowing their boundaries.

## Compatibility and upgrade notes

- Obsidian `1.7.2` or later is still required.
- Project Manager is required; direct task-editor navigation targets Project Manager `1.8.x`.
- The plugin ID remains `project-manager-insights`.
- No settings migration is required.
- Project Manager Insights does not modify project or task notes.

## Verification

- TypeScript type checking passes.
- Official Obsidian ESLint rules report no errors.
- All automated tests pass.
- The production bundle builds successfully.
- Desktop checks in the `dev-test` vault cover project-picker dismissal, task filters, table headers and resizing, member ratios, and Project Manager navigation.

This release contains no breaking changes to stored settings or Project Manager data.
