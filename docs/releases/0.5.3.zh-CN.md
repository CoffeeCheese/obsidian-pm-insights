# Project Manager Insights 0.5.3

[English](./0.5.3.md)

Project Manager Insights 0.5.3 为每位成员新增聚焦的个人仪表盘，优化个人交付账本文案，并在缺少 Project Manager 或交付门禁等前置条件时提供明确引导。

## 功能亮点

- 从所选成员姓名旁的仪表按钮打开独立右侧抽屉，无需继续展开和拉长成员详情页。
- 在一个视图中查看交付健康度、按截止节点排列的个人交付跑道、窗口内进展、计划负载、团队对比、工作构成和不受窗口限制的个人交付账本。
- 可选择 7、14、30 天负载窗口或自定义截止日期，并随时切换是否包含周末；容量会自动采用已配置的工作日或自然日每日工时。
- 点击风险原因、跑道节点、概要指标或项目构成后，抽屉会关闭并在源任务列表中筛出相关任务。
- 使用通俗的“团队参考”对比个人结果：将团队有效结果排序后取中间值，成员数为偶数时取中间两个值的平均，并以更清晰的“完成情况、工时执行、计划完整度”描述个人交付账本。
- 仅在成员相关项目缺少完整门禁时显示针对性提醒，说明受影响的窗口指标并可直接进入门禁设置，同时保留个人交付账本。
- 主动打开 PM Insights 时检测 Project Manager 是否缺失或停用，并引导用户前往 Obsidian 官方插件页面处理。

## 修复

- 修正个人仪表盘的成员归属、共享任务分摊、有效截止时间、全量账本比例、团队样本和项目构成，使每个视图使用预期统计范围。
- 阻止主题背景的横格线穿透抽屉，为各仪表分区提供稳定的跨主题表面。
- 优化窄工作区下的响应式布局和可读性，同时保留从洞察筛选返回源任务时的上下文。

## 统计口径说明

- 负载窗口从今天开始；有效截止时间依次取任务截止日期、阶段门禁、项目上线日期。
- 计划负载为截至窗口末日未完成的已估时承诺（含逾期承诺）除以个人可用容量；共享工作会在已识别负责人之间平均分摊。
- 窗口内进展纳入截至窗口末日应完成的未取消、未归档有效任务；已完成任务仅在有效截止时间不早于今天时进入窗口。个人交付账本继续使用成员完整的有效任务历史。
- 团队参考会将可用成员结果排序后取中间值，成员数为偶数时取中间两个值的平均；没有有效样本时显示暂无数据，而不是零。

## 兼容性与升级说明

- 已有设置会自动补齐个人仪表盘默认的 14 个工作日窗口，无需手动迁移。
- 直接打开任务详情继续支持 Project Manager `1.8.x` 和 `2.1.x`。
- 继续支持 Obsidian `1.7.2` 及以上版本。
- PM Insights 仍然不会写入 Project Manager 的项目与任务笔记。
