# Project Manager Insights 0.5.4

[简体中文](./0.5.4.zh-CN.md)

Project Manager Insights 0.5.4 rebuilds the personal dashboard as a focused delivery brief. It now connects stage-derived delivery windows, project-level workload, and cumulative capacity so one person can see not only what is due, but whether the work can still fit before each project delivery date.

## Highlights

- Open a centered, content-adaptive **Personal delivery brief** from the gauge beside a member's name, with clearer typography, denser use of space, and responsive layouts for narrower workspaces.
- Group projects and stages that share the same delivery date into one timeline window, showing task and planned-hour progress, remaining hours, cumulative load versus capacity, and concrete schedule or gate signals.
- Summarize the member's complete current workload by project. This view includes all valid unfinished work in the selected project scope and remains independent of the 7-, 14-, or 30-day delivery-window range.
- Replace the previous team-risk comparison with delivery-capacity checkpoints. Projects are ordered by delivery date, earlier commitments consume capacity before later ones, and each checkpoint exposes buffer, tight capacity, shortfall, or overdue work.
- Make capacity overflow visible through a marked capacity limit and striped over-capacity segment, while keeping unresolved stages and unestimated tasks visible as planning-confidence gaps.
- Select a delivery window, project workload row, capacity checkpoint, or confidence note to return to the member task list with the related source tasks filtered.

## Delivery-date and workload rules

- Group each member's work by project and assign the project commitment to the gate date of the farthest delivery stage covered by that work.
- Let parent work inherit the stages covered by its executable descendants; work spanning several stages uses the latest stage in the configured delivery order.
- Keep task due dates as schedule-risk signals without using them to position project delivery windows. A project launch date is no longer used as a fallback when the delivery stage cannot be resolved.
- Divide shared-task estimates, logged hours, and remaining hours evenly among resolved assignees.
- Exclude completed, cancelled, and archived work from current project workload while retaining unestimated work as a visible planning gap instead of inventing hours.
- Apply the planning range only to the delivery-window timeline. Project workload and delivery-capacity checkpoints continue to cover all current work; weekend inclusion changes schedule-day and capacity calculations, not workload membership.

## Fixes

- Rebuild window progress from the complete task graph so completed work remains part of the denominator and numerator even when gate-risk analysis exposes only open tasks; delivery windows no longer remain incorrectly at `0%`.
- Prevent theme-level button hover styles from moving delivery-window nodes, adding unintended surfaces, or hiding the vertical timeline route.
- Keep timeline routes inside their window rows and preserve them across hover, focus, and active states.
- Improve the personal brief's information hierarchy, font sizing, scroll behavior, and use of available modal space.

## Compatibility and upgrade notes

- Existing personal-dashboard settings continue to work without manual migration.
- Direct task-detail opening continues to support Project Manager `1.8.x` and `2.1.x`.
- Obsidian `1.7.2` or later remains supported.
- PM Insights remains read-only for Project Manager project and task notes.
