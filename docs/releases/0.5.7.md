# Project Manager Insights 0.5.7

[简体中文](./0.5.7.zh-CN.md)

Project Manager Insights 0.5.7 improves compatibility with Project Manager 2.3.1, restoring task navigation and keeping project and task statistics aligned with the native plugin.

## Highlights

- Open the native task editor based on available capabilities, without restricting Project Manager version numbers.
- Honor Project Manager's preference for editing tasks in a modal or a tab.
- Recognize both legacy IDs and wikilink references when associating tasks with projects and parents.
- Use Project Manager's native index when available, including projects outside the default creation folder, discovery exclusions, archive state, and project-specific completion statuses.
- Preserve folder-based discovery for older Project Manager versions and keep task editing in the native plugin.

## Verification

- TypeScript checking, Obsidian ESLint rules, official-review checks, all 173 automated tests, and the production build pass.
- Navigation coverage includes 24 cases for modal and tab editors, simulated future version numbers, and unavailable editor capabilities.
- Verified with Project Manager 2.3.1 in Obsidian: task and parent associations, opening the requested task in both editor surfaces, and cleanup after closing.
