# Project Manager Insights 0.5.6

[English](./0.5.6.md)

Project Manager Insights 0.5.6 新增项目级“同日门禁容量”规则，让特殊的上线日排期能够被明确配置，同时保持现有项目的默认统计行为不变。

## 功能亮点

- 在每个项目的交付门禁编辑器中新增**同日门禁容量**开关。当相邻阶段门禁落在同一天，但当天仍应作为一个可用交付日时，可以为该项目单独启用。
- 在现有“自然日 / 工作日”项目时钟旁，以 `08 → 1 天` 或 `08 → 0 天` 即时预览规则结果。
- 将项目选择的规则一致应用到阶段窗口天数、门禁风险指标、成员交付承诺与个人交付简报的容量对比。
- 规则按项目独立保存；已有项目和新建项目默认仍将同日门禁计为 0 天，只有显式启用后才改变。

## 计算规则

- 普通阶段窗口继续沿用现有的“前一门禁日之后，到当前门禁日为止”`(前一门禁, 当前门禁]` 口径。
- 启用后，自然日模式下的同日门禁提供 1 天容量。
- 工作日模式下，同一工作日提供 1 天容量；同一周末日期仍为 0 天。
- 已流逝天数、延期、逾期、剩余天数与项目总周期等通用时钟不受影响。
- 多个项目共用同一个同日容量节点时，个人交付简报只计算一个共享可用日，不会按项目重复叠加容量。

## 验证

- TypeScript 类型检查、Obsidian ESLint 规则、官方审核回归检查、全部 146 项自动化测试和生产构建通过。
- 回归测试覆盖旧配置迁移、规则持久化、工作日与周末行为、门禁风险传递和个人交付容量统计。
- 功能构建已安装并热重载到 `Obsd` Vault，未发现插件错误；已有项目配置保持不变，并安全地默认关闭新规则。
