# Project Manager Insights 0.6.0

[English](./0.6.0.md)

Project Manager Insights 0.6.0 新增项目上线确认、可追溯的上线记录，并统一不同主题下的表单控件样式。

## 功能亮点

- 已选项目名称旁以紧凑的 **未上线 / 待确认上线 / 已上线** 状态打开独立上线面板，门禁风险详情的上线节点也提供入口。
- 验收及前置门禁通过后，可登记实际上线日期。保存成功后播放一次上线动画，并展示实际日期与原计划、已确认预计日期的偏差。
- 结果卡下方常驻 **更正上线日期** 和 **撤销上线标记** 两项操作；均要求填写原因，并在时间轴中保留完整历史。
- 上线后的延期计划只供查阅。撤销上线标记会恢复此前的延期状态；重新打开的任务仍会显示，但不会抹去上线事实。
- 设置写入按顺序执行，保存成功后再发布状态，避免保存失败或并发写入导致界面与持久化数据不一致。
- 修复 Pixel 主题边框、焦点轮廓与 Obsidian 焦点阴影叠加的问题。日期、文本、数字、下拉及组合输入控件统一使用局部作用的细边框和单道焦点提示。
- 中英文 README 补充项目上线状态入口与上线记录面板截图。

## 升级说明

上线确认用于登记已经核验的部署结果，不会执行部署、归档项目或修改任务笔记。所有项目均需人工确认上线，包括没有延期历史的项目。已有合法上线日期继续有效；此前仅因验收通过而自动视为上线的项目，升级后会等待确认。

旧记录无法安全确定此前延期状态时，插件会保留当前上线记录，并说明缺失信息。本次不提高 Obsidian 最低版本要求。
