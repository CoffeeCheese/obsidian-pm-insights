# Project Manager Insights 0.3.0

[简体中文](./0.3.0.zh-CN.md)

Project Manager Insights 0.3.0 adds delivery-progress tracking across the full task trees in your selected projects, with guided tag mappings and acceptance-aware completion signals.

## Highlights

### Delivery progress from task trees

- Track design, development, testing, acceptance, and weighted total progress independently of the assignee and task-drawer filters.
- Classify design, development, and testing leaf tasks with configurable Project Manager task tags. Hierarchical mappings such as `type/dev` also include `type/dev/frontend`.
- Calculate acceptance from root tasks: a root is accepted only when it and every required preceding stage are complete. The dashboard separately shows roots that are ready for acceptance.
- Configure stage weights, choose which stages are required before acceptance, and optionally skip stages that have no matching work. Settings prevent conflicting tag hierarchies and require weights to total 100%.
- Pick mappings from tags already in Project Manager tasks, with task usage counts and conflict guidance, while retaining manually entered tags.
- Surface delivery data-quality signals for unclassified or conflicting tags, tasks without a root, missing acceptance prerequisites, and roots completed prematurely.

### Faster navigation and settings access

- Open a task in Project Manager from PM Insights when its project is viewed in Kanban, Table, or Gantt mode.
- Open PM Insights settings directly from the dashboard header.

## Compatibility and upgrade notes

- Obsidian `1.7.2` or later remains supported.
- Project Manager remains required. Direct task-editor opening continues to support Project Manager `1.8.x`.
- Existing installations receive the default delivery-progress configuration automatically; no note or manual settings migration is required.
- The plugin ID remains `project-manager-insights`.
- Project Manager Insights remains read-only and does not modify project or task notes.
