# Project Manager Insights 0.5.2

[English](./0.5.2.md)

Project Manager Insights 0.5.2 在最终上线提醒中新增按负责人瓶颈评估工期容量的能力，并修复在交付门禁日历中翻月时误选日期的问题。

## 功能亮点

- 在每个有效阶段门禁和上线日期前，分别对比负责人剩余工时与个人可用容量，不再把整个团队视为一个串行资源。
- 不同负责人并行计算，同一负责人跨阶段的未完成工作继续累加；分组前会统一成员别名，共享任务工时则在多位负责人之间平均分摊。
- 集中展示项目剩余总工时、瓶颈负责人、瓶颈负载、工时缺口或余量、负责人并行负载，以及可展开的各节点容量明细。
- 上线提醒默认保持收起；打开后直接呈现负责人容量，并提供清晰的展开与收起标记，同时优化窄面板下的响应式布局。
- 可在 **设置 → PM Insights → 门禁风险规则** 中分别配置每人每个工作日与自然日的可用工时，两者默认均为 8 小时。

## 修复

- 在原生交付门禁日期控件中切换上一个月或下一个月时，不再误选临时日期、关闭日历或触发编辑器重绘。
- 仅在用户确认日期变化后提交数据，同时保持正常日期选择和上线日期登记流程不变。

## 兼容性与升级说明

- 已有设置会自动补齐工作日与自然日每天 8 小时的容量默认值，无需手动迁移。
- 直接打开任务详情继续支持 Project Manager `1.8.x` 和 `2.1.x`。
- 继续支持 Obsidian `1.7.2` 及以上版本。
- PM Insights 仍然不会写入 Project Manager 的项目与任务笔记。

## 验证

- TypeScript 类型检查、Obsidian ESLint 规则与官方审核回归检查通过。
- 14 个测试文件中的 110 项自动化测试全部通过，覆盖负责人容量聚合与设置兼容性。
- 真实 `dev-test` Vault 检查确认：日历翻月会保持打开直到用户确认日期，上线提醒能够展示预期的负责人容量节点。
- 生产构建成功。
