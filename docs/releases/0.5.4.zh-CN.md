# Project Manager Insights 0.5.4

[English](./0.5.4.md)

Project Manager Insights 0.5.4 将个人仪表盘重构为聚焦交付判断的个人交付简报。新版把阶段推导的交付窗口、项目级工作负载和累计交付容量连接起来，让成员既能看到需要交付什么，也能判断现有工作能否装入每个项目交付日前的剩余容量。

## 功能亮点

- 从成员姓名旁的仪表按钮打开居中且内容自适应的**个人交付简报**，通过更清晰的字体层级、更紧凑的空间利用和响应式排版适配不同宽度的工作区。
- 将交付日期相同的项目与阶段合并到同一个时间轴窗口，集中展示任务与计划工时进展、剩余工时、累计负载与容量，以及具体的排期和门禁信号。
- 按项目汇总成员当前的完整工作负载。该视图纳入所选项目范围内全部有效未完成工作，不受 7、14、30 天交付窗口范围限制。
- 使用交付容量节点替代原有的团队风险对比。项目按交付日排序，较早承诺会先占用后续容量，每个节点会直接显示余量、临界、缺口或逾期状态。
- 通过容量上限刻度和斜纹超载区直观展示无法在交付日前装下的工时，同时把阶段无法解析和任务未估时作为计划置信缺口保留下来。
- 点击交付窗口、项目工作负载行、容量节点或置信提示，可返回成员任务列表并筛选对应源任务。

## 交付日期与工作负载口径

- 先按成员和项目归集工作，再以该成员在项目中覆盖的最远交付阶段确定项目承诺的门禁日期。
- 父任务会继承其可执行后代覆盖的阶段；跨越多个阶段的工作使用配置顺序中的最远阶段。
- 任务截止日期继续作为排期风险信号，但不再用于定位项目交付窗口；无法解析交付阶段时，也不会再用项目上线日期兜底。
- 共享任务的计划工时、已登记工时和剩余工时会在已识别的负责人之间平均分摊。
- 当前项目工作负载排除已完成、已取消和已归档工作；未估时任务仍会作为计划缺口显示，不会虚构工时。
- 规划范围只控制时间轴中的交付窗口。项目工作负载和交付容量始终覆盖全部现有工作；是否包含周末只改变计划日与容量计算，不改变工作负载的任务范围。

## 修复

- 使用完整任务树重建窗口进展，使已完成工作在门禁风险仅暴露未完成任务时仍能进入分子和分母，修复交付窗口错误地长期显示 `0%` 的问题。
- 阻止主题级按钮悬浮样式移动交付节点、添加异常表面或遮住时间轴竖线。
- 将时间轴轨线约束在各交付窗口行内部，并在悬浮、聚焦和激活状态下保持可见。
- 优化个人交付简报的信息层级、字号、滚动行为和弹窗空间利用率。

## 兼容性与升级说明

- 现有个人仪表盘设置可以继续使用，无需手动迁移。
- 直接打开任务详情继续支持 Project Manager `1.8.x` 和 `2.1.x`。
- 继续支持 Obsidian `1.7.2` 及以上版本。
- PM Insights 仍然不会写入 Project Manager 的项目与任务笔记。
