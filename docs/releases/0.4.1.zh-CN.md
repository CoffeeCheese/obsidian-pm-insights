# Project Manager Insights 0.4.1

[English](./0.4.1.md)

Project Manager Insights 0.4.1 让交付进度可以直接对照 Project Manager 中已经配置的排期。开发、测试和验收阶段现在会同时展示截至今天的预计进度、实际进度相对计划的偏移量，以及预计进度在轨道上的位置。

## 重点更新

### 各交付阶段直接展示预计进度

- 在开发、测试和验收阶段名称后，以紧凑的 `预计% / ±偏移%` 形式展示计划位置，例如 `0% / +44.4%`。
- 通过颜色区分领先、落后和符合计划三种状态，减少文字占用并提升扫读效率。
- 实际完成百分比继续独立右对齐，避免与计划信息混淆。

### 基于 Project Manager 数据计算计划目标

- 预计进度来自相关 Project Manager 项目已配置的交付门禁排期。
- 跨项目汇总时按项目实际承载的工作量加权：开发、测试阶段使用阶段任务数，验收阶段使用主任务数。
- 当任一相关项目缺少适用的门禁排期时，不展示不完整的汇总结果，避免形成误导。

### 更直观的进度轨道与详情

- 在每个阶段的进度轨道上增加预计进度标记，可以直接对照实际与计划位置。
- 鼠标悬停或键盘聚焦时，使用紧凑的定制提示窗分别展示“预计”和“偏移”。
- 紧凑展示与提示窗统一使用 `%`，包括 `+44.4%`、`−8%`、`±0%` 等带符号数值。
- 对未配置排期或暂无可比较任务的情况提供清晰说明，同时避免挤占阶段卡片的默认空间。

### 交互与文档优化

- 移除鼠标经过整个“交付进度”区域时出现的不协调默认提示框，同时保留无障碍区域名称。
- 优化阶段卡片的间距与响应式布局，使新增的计划信息在窄屏下仍然清晰。
- 聚焦中英文 README 的功能截图，并清理已被替换的旧图片资源。

## 兼容性与升级说明

- 继续支持 Obsidian `1.7.2` 及以上版本。
- 仍然依赖 Project Manager，且 Project Manager Insights 保持只读分析。
- 本次升级不会改写项目笔记、任务笔记、Project Manager 元数据或已经配置的门禁排期。
- 插件 ID 仍为 `project-manager-insights`。

本次升级不会破坏 Project Manager 数据或已有 PM Insights 设置。
