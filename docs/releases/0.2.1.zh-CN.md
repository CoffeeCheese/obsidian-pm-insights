# Project Manager Insights 0.2.1

[English](./0.2.1.md)

Project Manager Insights 0.2.1 是一次兼容性与审查质量更新，修复了 Obsidian 官方插件自动审查中前四项可处理问题。本版本不会改变工作量计算规则或 Project Manager 数据。

## 变更内容

- 为 Obsidian 1.13 及更高版本补充可被设置搜索索引的声明式设置定义。
- 为 Obsidian 1.7.2 至 1.12.x 保留原有命令式设置渲染作为兼容回退路径。
- 在两套设置实现中保持语言选择、成员别名编辑和 Insights 实时刷新行为一致。
- 在英文和简体中文 README 中使用精确的 Markdown 标题，让自动审查可以与插件清单名称正确匹配。
- 移除任务筛选中的无效类型断言，并避开由此暴露的不安全迭代器取值路径。
- 移除两处不必要的 CSS `!important`，同时继续隐藏原生折叠标记。
- 新增可重复执行的官方审查回归检查，并让 ESLint 警告直接阻断本地验证流程。

## 兼容性

- 继续支持 Obsidian `1.7.2` 或更高版本。
- 不需要迁移已有设置。
- 插件 ID 继续保持为 `project-manager-insights`。
- Project Manager Insights 仍保持只读，不会修改项目或任务笔记。

## 验证结果

- TypeScript 类型检查通过。
- Obsidian 官方 ESLint 规则以零警告通过。
- README 标题、CSS 强制覆盖和任务筛选断言的官方审查回归检查通过。
- 全部自动化测试通过。
- 生产构建成功。
- 已在 `dev-test` Vault 的当前 Obsidian 桌面版本中验证设置渲染和折叠标记样式。

本版本不会对已有设置、Project Manager 数据或工作量计算规则造成破坏性变更。
