# Project Manager Insights 0.2.1

[简体中文](./0.2.1.zh-CN.md)

Project Manager Insights 0.2.1 is a compatibility and review-quality release that addresses the first four actionable findings from Obsidian's automated plugin review. It does not change workload calculations or Project Manager data.

## Changes

- Add declarative, searchable setting definitions for Obsidian 1.13 and later.
- Keep the existing imperative settings renderer as a fallback for Obsidian 1.7.2 through 1.12.x.
- Preserve language selection, member-alias editing, and live Insights refresh behavior across both settings implementations.
- Match the English and Simplified Chinese README titles exactly to the manifest name.
- Remove an unnecessary task-filter type assertion and avoid the unsafe iterator value path it exposed.
- Remove two unnecessary CSS `!important` declarations while retaining hidden native disclosure markers.
- Add a repeatable official-review regression check and make ESLint warnings fail the local verification pipeline.

## Compatibility

- Obsidian `1.7.2` or later remains supported.
- No settings migration is required.
- The plugin ID remains `project-manager-insights`.
- Project Manager Insights remains read-only and does not modify project or task notes.

## Verification

- TypeScript type checking passes.
- Official Obsidian ESLint rules pass with zero warnings.
- Official-review regression checks pass for README titles, CSS overrides, and the task-filter assertion.
- All automated tests pass.
- The production bundle builds successfully.
- Desktop verification in the `dev-test` vault confirms settings rendering and disclosure-marker styling on the current Obsidian release.

This release contains no breaking changes to stored settings, Project Manager data, or workload calculations.
