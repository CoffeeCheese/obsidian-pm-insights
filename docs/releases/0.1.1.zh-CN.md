# PM Insights 0.1.1

[English](./0.1.1.md)

PM Insights 0.1.1 是根据 Obsidian 官方社区目录自动审查结果准备的兼容性与质量修复版本。

## 变更内容

- 使用 Obsidian `Setting` 标题替代手工创建的 HTML 标题。
- 将设置页宿主类型与 Obsidian 新版插件设置 API 分离，继续兼容 Obsidian 1.7.2 及更高版本。
- 在 Project Manager 工具栏集成中使用 Obsidian DOM 助手和跨窗口安全的元素检查。
- 使用窗口作用域的动画帧 API，改善弹出窗口兼容性。
- 调整异步界面事件，避免向 DOM 监听器返回 Promise。
- 使用 Node.js 内置模块元数据替代已弃用的 `builtin-modules` 构建依赖。
- 将 Obsidian 官方 ESLint 规则加入本地验证流程。

## 验证结果

- TypeScript 类型检查通过。
- Obsidian 官方 ESLint 规则无错误。
- 全部自动化测试通过。
- 生产构建成功。

本版本不会更改已有设置或工作量计算逻辑。
