# Project Manager Insights 0.6.3

[简体中文](./0.6.3.zh-CN.md)

Project Manager Insights 0.6.3 adds a completion-time column to the member task list and improves the personal delivery brief's capacity layout.

## Highlights

- See each completed task's native completion date in the member task list. A recorded time is shown in the device's local time; date-only records keep their date, and missing or invalid values show a dash. The column is available alongside the existing task filters and resizable columns.
- Read capacity checkpoints without overlapping text when a stage description or load status is long. The date and capacity state share the first line, while the stage-window description has its own line. The cumulative and new-load figures can also adapt to narrow cards.

## Upgrade notes

No migration or new setting is required. Completion times are read from Project Manager's existing task data; this plugin does not edit task notes. The minimum Obsidian version remains 1.7.2.

## Verification

- TypeScript, Obsidian ESLint, official-review checks, all 215 automated tests, and the production build pass.
- The capacity layout was checked in the dev-test vault with the reported text and a denser case at three card widths. The plugin was also installed and reloaded in Obsd from the same source before this release.
