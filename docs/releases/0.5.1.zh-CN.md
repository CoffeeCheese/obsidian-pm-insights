# Project Manager Insights 0.5.1

[English](./0.5.1.md)

Project Manager Insights 0.5.1 修复升级 Project Manager `2.1.x` 后无法直接打开任务详情的问题，同时继续兼容 Project Manager `1.8.x`。

## 修复

- 允许 Project Manager `2.1.x` 继续使用现有原生任务编辑器桥接，不再在导航开始前被版本检查拦截。
- 保留已验证的 Project Manager `1.8.x` 导航路径，尚未升级的用户仍可正常使用。
- 在真实 Vault 导航检查中准确捕获“版本不支持”提示，使后续兼容性回归能够给出明确失败信号。

## 兼容性与升级说明

- 直接打开任务详情支持 Project Manager `1.8.x` 和 `2.1.x`。
- 继续支持 Obsidian `1.7.2` 及以上版本。
- 本次发布不涉及设置或数据迁移。
- PM Insights 仍然不会写入 Project Manager 的项目与任务笔记。

## 验证

- TypeScript 类型检查、Obsidian ESLint 规则与官方审核回归检查通过。
- 13 个测试文件中的 98 项自动化测试全部通过，其中包含 Project Manager `1.8.0` 与 `2.1.0` 的导航覆盖。
- Project Manager `2.1.0` 环境下的真实 Obsd Vault 导航检查通过。
- 生产构建成功。
