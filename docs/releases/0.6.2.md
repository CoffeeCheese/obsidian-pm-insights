# Project Manager Insights 0.6.2

[简体中文](./0.6.2.zh-CN.md)

Project Manager Insights 0.6.2 adds **Completed today** to the personal delivery brief.

## Highlights

- See today's completed task count and a timeline beside delivery windows and workload on wide screens. The timeline moves below the planning content when the window is narrow.
- Read each task's completion time, title, and project, then open the source task in Project Manager. Long titles wrap without covering the list note.
- Interpret native `completed` values using the device's local day and time zone. Date-only records are labelled **Date only** and follow records with a known time. Tasks marked complete without a usable completion date are excluded from today's count, with an explanation in the empty state.
- Keep the list aligned with the selected member, projects, archive and parent-task settings, and member aliases. Shared tasks appear once per member. Changes to task data refresh an open brief, and the date rolls over at local midnight.

## Upgrade notes

No migration or new setting is required. The feature reads Project Manager's existing task completion field and does not edit task notes. The planning range does not limit today's completed list. The minimum Obsidian version remains 1.7.2.

## Verification

- TypeScript, Obsidian ESLint, official-review checks, all 215 automated tests, and the production build pass.
- The dev-test vault was used to verify native completion dates, task opening, live refresh, the local midnight rollover, keyboard operation, and narrow and long-title layouts. Temporary native task fixtures were removed afterward.
