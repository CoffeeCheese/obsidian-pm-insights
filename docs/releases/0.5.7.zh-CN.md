# Project Manager Insights 0.5.7

[English](./0.5.7.md)

Project Manager Insights 0.5.7 改进与 Project Manager 2.3.1 的兼容性，恢复任务导航，并让项目与任务统计保持与原生插件一致。

## 功能亮点

- 根据实际可用能力打开原生任务编辑器，不再限制 Project Manager 版本号。
- 遵循 Project Manager 的任务编辑偏好，支持弹窗和标签页两种方式。
- 同时识别旧版 ID 和 wikilink 引用，正确关联任务所属项目与父任务。
- 在可用时复用 Project Manager 原生索引，支持默认创建目录外的项目、索引排除规则、归档状态和项目独立的完成状态配置。
- 为旧版 Project Manager 保留按配置目录发现项目的方式，任务编辑继续由原生插件负责。

## 验证

- TypeScript 类型检查、Obsidian ESLint 规则、官方审核检查、全部 173 项自动化测试和生产构建通过。
- 24 项导航测试覆盖弹窗、标签页、模拟未来版本号及编辑能力不可用的情况。
- 已在 Obsidian 中使用 Project Manager 2.3.1 验证任务与父任务关联、两种编辑方式打开指定任务，以及关闭后的视图清理。
