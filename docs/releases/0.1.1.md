# PM Insights 0.1.1

[简体中文](./0.1.1.zh-CN.md)

PM Insights 0.1.1 is a compatibility and quality release prepared in response to the Obsidian Community directory's automated review.

## Changes

- Use Obsidian `Setting` headings instead of manual HTML headings.
- Keep the settings host type separate from Obsidian's newer plugin settings API, preserving compatibility with Obsidian 1.7.2 and later.
- Use Obsidian DOM helpers and cross-window-safe element checks in the Project Manager toolbar integration.
- Use window-scoped animation frame APIs for popout compatibility.
- Handle asynchronous UI events without returning promises to DOM listeners.
- Replace the deprecated `builtin-modules` build dependency with Node.js built-in module metadata.
- Add the official Obsidian ESLint rules to the local verification pipeline.

## Verification

- TypeScript type checking passes.
- Official Obsidian ESLint rules report no errors.
- All automated tests pass.
- The production bundle builds successfully.

There are no changes to stored settings or workload calculations in this release.
