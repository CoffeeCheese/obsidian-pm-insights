# Project Manager Insights 0.5.6

[简体中文](./0.5.6.zh-CN.md)

Project Manager Insights 0.5.6 adds a project-level clock rule for delivery stages that share the same gate date, keeping exceptional release-day planning explicit without changing the default behavior of existing projects.

## Highlights

- Add a **Same-day gate capacity** switch to each project's delivery-gate editor. Enable it when two consecutive gates occur on the same date but that date still represents a usable delivery day.
- Show the rule as an immediate `08 → 1 day` or `08 → 0 days` preview alongside the existing calendar-day or workday clock choice.
- Apply the selected rule consistently to stage-window duration, gate risk metrics, member delivery commitments, and the personal delivery brief's capacity comparison.
- Keep the rule project-specific: existing and newly created projects default to zero days for same-day gates until the option is explicitly enabled.

## Calculation rules

- Normal stage windows retain the existing `(previous gate, current gate]` calculation.
- With the option enabled, equal gate dates contribute one day in calendar-day mode.
- In workday-only mode, an equal weekday gate contributes one day while an equal weekend gate remains zero days.
- Elapsed time, delays, overdue indicators, remaining-day clocks, and the overall project duration are unchanged.
- When multiple projects share a same-day capacity checkpoint, the personal brief counts one shared available day rather than stacking one day per project.

## Verification

- TypeScript checking, Obsidian ESLint rules, official-review regression checks, all 146 automated tests, and the production build pass.
- Regression coverage includes legacy-setting migration, explicit persistence, weekday and weekend behavior, gate-risk propagation, and personal delivery capacity.
- The feature build was installed and hot-reloaded in the `Obsd` Vault with no plugin errors; existing project settings remained unchanged and defaulted safely to the disabled rule.
