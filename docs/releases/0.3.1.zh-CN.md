# Project Manager Insights 0.3.1

[English](./0.3.1.md)

Project Manager Insights 0.3.1 让交付健康度更容易查看和处理。本版本新增可配置的交付门禁、可下钻到具体任务的交付异常，以及更清晰的已选项目范围展示，同时完善验收与跳过阶段的判定语义。

## 版本亮点

### 可配置的交付门禁与排期风险

- 可为每个已配置交付阶段、验收门禁和所选项目的最终上线提醒设置按自然日计算的日期计划。
- 将实际进度与门禁日期对应的预期进度进行比较，明确展示正常、需关注、高风险、已逾期和已通过状态。
- 可查看风险信号背后的具体任务，包括任务逾期、截止日在门禁之后、缺少截止日、缺少估时、未分配成员和验收阻塞项。
- 普通阶段只分析自身任务；验收与上线提醒会额外关注验收阻塞任务。
- 最终上线门禁只作为计划提醒，项目是否达到交付标准仍由验收进度决定。
- 保留跳过阶段的真实语义：允许空阶段跳过时，该阶段会通过，但不会被误报为逾期，也不会虚构通过时间。

### 可操作的交付异常

- 点击交付异常 Banner，可查看缺少前置条件和主任务提前完成所对应的具体任务。
- 可按异常分类筛选，并直接在 Project Manager 中打开任务；关闭任务编辑窗口后会返回交付异常详情。
- 可自主选择是否继续校验已经完成的主任务是否满足前置阶段；已有安装默认维持开启，直到用户主动修改。
- 验收进度要求真实的完成依据，仅将任务移动到“验收中”等进行中泳道不会计为验收通过。

### 更清晰的项目范围与面板控制

- 在面板的项目范围栏直接看到全部已选项目，并通过紧凑的关闭控件移除单个项目。
- 可从面板隐藏或恢复交付进度区域，显示偏好会持久化到设置。
- 优化重置筛选、进度显隐、异常分类、弹窗空状态、悬停、提示气泡和键盘焦点交互，使弹窗切换过程更紧凑稳定。

## 兼容与升级说明

- 继续支持 Obsidian `1.7.2` 或更高版本。
- 仍需要安装 Project Manager；Project Manager Insights 继续保持只读。
- 门禁排期和“已完成主任务前置校验”偏好保存在插件设置中，不会修改项目或任务笔记。
- 已有交付进度设置会自动迁移；在用户为项目补充日期前，门禁排期保持未配置状态。
- 插件 ID 继续保持为 `project-manager-insights`。
