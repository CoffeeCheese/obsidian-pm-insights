# Project Manager Insights 0.6.1

[English](./0.6.1.md)

Project Manager Insights 0.6.1 在项目下拉中展示上线状态，并修复 Project Manager 更新或项目迁移后无法打开任务的问题。

## 功能亮点

- 项目下拉列表显示 **已上线 / 未上线**。已上线项目使用绿色勾选标记，悬停可查看实际上线日期；长项目名自动换行，状态保持完整显示。
- 项目迁移后按当前路径打开任务，同时验证项目身份与任务归属，避免原任务删除后误开另一项目中同 ID 的任务。
- Project Manager 更新或热重载导致索引实例替换时，自动重新订阅并刷新数据。接口兼容的常规更新无需再手动重载 PM 洞察。
- 原生索引加载中或 Project Manager 暂时不可用时，保留上一份有效数据；首次索引就绪后自动刷新空界面，同时继续反映已就绪索引中的真实删除操作。

## 升级说明

安装本版本后需重载一次 PM 洞察。后续兼容的 Project Manager 更新会自动识别；未来上游接口发生变化时仍可能需要适配。

保留现有上线记录、设置和任务笔记。任务打开方式继续遵循 Project Manager 的弹窗或标签页偏好。缺少原生索引能力的旧版集成保留按原路径打开的行为。本插件最低 Obsidian 版本仍为 1.7.2；Project Manager 自身的最低版本要求独立适用。

## 验证

- TypeScript 类型检查、Obsidian ESLint、官方审核检查、全部 205 项自动化测试及生产构建通过。
- 在 dev-test 中使用 Project Manager 2.4.1 验证弹窗和标签页均打开正确任务、临时视图清理正常、任务文件内容未改变。
- 已在 Obsd 验证真实任务导航。回归测试覆盖加载与热重载、首次就绪通知、迁移路径及跨项目重复任务 ID。
