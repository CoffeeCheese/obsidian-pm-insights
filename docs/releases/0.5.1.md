# Project Manager Insights 0.5.1

[简体中文](./0.5.1.zh-CN.md)

Project Manager Insights 0.5.1 restores direct task-detail navigation after upgrading Project Manager to `2.1.x`, while retaining compatibility with Project Manager `1.8.x`.

## Fixes

- Allow the existing native task-editor bridge to run with Project Manager `2.1.x` instead of rejecting the version before navigation begins.
- Preserve the tested Project Manager `1.8.x` navigation path for users who have not upgraded.
- Detect the exact unsupported-version notice in the real-Vault navigation check so future compatibility regressions fail with a precise signal.

## Compatibility and upgrade notes

- Direct task-detail opening is supported with Project Manager `1.8.x` and `2.1.x`.
- Obsidian `1.7.2` or later remains supported.
- This release introduces no settings or data migrations.
- PM Insights remains read-only for Project Manager project and task notes.

## Verification

- TypeScript checking, Obsidian ESLint rules, and official-review regression checks pass.
- All 98 automated tests pass across 13 test files, including navigation coverage for Project Manager `1.8.0` and `2.1.0`.
- The real Obsd Vault navigation check passes with Project Manager `2.1.0`.
- The production bundle builds successfully.
