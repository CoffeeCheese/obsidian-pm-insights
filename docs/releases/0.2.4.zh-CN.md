# Project Manager Insights 0.2.4

[English](./0.2.4.md)

Project Manager Insights 0.2.4 将 Project Manager 任务标签带入任务列表，使任务上下文与工作量提示能够在同一处查看。

## 版本亮点

### Project Manager 任务标签

- 在任务列表中，将每个任务的 Project Manager 标签展示在任务标题下方。
- 标签复用“未估算”等现有任务徽标样式，保持任务行视觉一致。
- 展示简洁的标签名称，不包含 `#` 前缀。
- 同时支持 Project Manager 任务 frontmatter 中的标签数组与单个字符串格式。
- 当来源笔记的标签元数据变化时，增量更新对应任务标签。

## 兼容与升级说明

- 继续支持 Obsidian `1.7.2` 或更高版本。
- 仍需要安装 Project Manager。
- 不需要迁移设置或笔记数据。
- 插件 ID 继续保持为 `project-manager-insights`。
- Project Manager Insights 仍保持只读，不会修改项目或任务笔记。

- 官方审查回归检查通过。
