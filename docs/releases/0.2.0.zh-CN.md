# Project Manager Insights 0.2.0

[English](./0.2.0.md)

Project Manager Insights 0.2.0 将成员详情面板升级为更完整的任务分析工作区。本版本新增个人交付比率、可组合的任务筛选、可调节列宽和 Project Manager 直接联动，同时收紧每一项汇总数据背后的任务统计口径。

## 版本亮点

### 三组六项个人比率

成员标题区域现在会紧凑展示六项比率，不再把任务列表整体向下挤压：

- **交付：**任务闭环、计划工时闭环。
- **工时：**工时消耗、超支任务。
- **数据基础：**估算命中、估算覆盖。

没有有效样本的比率会显示短横线，而不会误报为 0%。当 Obsidian 左侧边栏展开、详情区域变窄时，比率摘要也会自动适应可用宽度。

### 项目与状态任务筛选

成员任务面板现在支持：

- 根据当前成员任务中实际出现的项目生成多选项目筛选。
- 根据同一任务列表中实际出现的状态生成多选状态筛选。
- 组合使用文本、项目和状态筛选。
- 全选、清空、重置、点击外部收起，以及按 `Escape` 收起。

可见任务计数会明确展示当前筛选条件产生的结果。

### 可调节且对齐一致的任务列

任务表格现在可以通过鼠标拖拽或键盘调整列宽，双击分隔线即可恢复默认宽度。表头与记录内容遵循相同的左对齐规则；当其他字段需要横向滚动时，任务列仍会保持可用。

### 与 Project Manager 直接联动

- 点击任务标题，会直接在当前 Insights 视图上方打开 Project Manager 的任务编辑弹窗。
- 点击项目名称，会在新的 Obsidian 页签中打开对应的 Project Manager 项目页。
- 任务标题和项目名称保留原有文本样式，不会显示成凸起的按钮。

直接打开任务编辑器目前支持 Project Manager `1.8.x`。Project Manager Insights 仍保持只读；任务编辑器中的修改由 Project Manager 自身负责。

## 统计与数据质量调整

- 在数据质量摘要中直接展示纳入统计的子任务总数。
- 明确标记为 `type: task` 的根记录不参与统计，即使它当前没有子任务。
- 当类型元数据缺失时，继续根据 `parentId` 关系推断父任务。
- 在子任务总数旁同步展示未估算、未分配和已排除父任务的数量。

这些规则可以避免需求级任务或其他父任务仅仅因为子任务列表为空，就被误计为可执行子任务。

## 交互与视觉优化

- 项目菜单会在点击其外部区域时自然收起。
- 筛选菜单会保持在列宽拖拽手柄上方，并移除了意外出现的竖向分隔线。
- 个人比率会利用成员姓名右侧的空白区域，不再在标题与任务数据之间增加大块面板。
- 较窄的成员详情区域也能完整容纳比率摘要，不再溢出面板边界。

## 兼容与升级说明

- 仍要求 Obsidian `1.7.2` 或更高版本。
- 需要安装 Project Manager；直接打开任务编辑器的能力面向 Project Manager `1.8.x`。
- 插件 ID 继续保持为 `project-manager-insights`。
- 不需要迁移已有设置。
- Project Manager Insights 不会修改项目或任务笔记。
