# Project Manager Insights 0.6.1

[简体中文](./0.6.1.zh-CN.md)

Project Manager Insights 0.6.1 shows launch status in the project picker and fixes task navigation after Project Manager updates or project migrations.

## Highlights

- See **Launched / Not launched** beside every project in the picker. Launched projects use a green check and reveal the actual launch date on hover. Long project names wrap while status labels remain visible.
- Open tasks using the current project path after a migration. Navigation verifies project identity and task ownership, preventing a deleted task from opening a same-ID task in another project.
- Automatically reconnect when a Project Manager update or reload replaces its index. Routine updates with compatible APIs no longer require manually reloading Insights.
- Preserve the last valid snapshot while the native index loads or Project Manager is temporarily unavailable. Refresh an initially empty view when the first index becomes ready, while still reflecting genuine deletions from a ready index.

## Upgrade notes

Reload Insights once when installing this version. Subsequent compatible Project Manager updates are detected automatically; future upstream API changes may still require an adaptation.

Existing launch records, settings, and task notes are preserved. Task navigation continues to honor Project Manager's modal or tab preference. Older integrations without native index capabilities retain path-based navigation. The minimum Obsidian version remains 1.7.2; Project Manager has its own minimum version requirements.

## Verification

- TypeScript, Obsidian ESLint, official-review checks, all 205 automated tests, and the production build pass.
- Project Manager 2.4.1 checks in dev-test cover correct-task navigation in modal and tab modes, temporary-view cleanup, and unchanged task content.
- Real task navigation was verified in Obsd. Regression tests cover loading and reload transitions, initial-ready notifications, migrated paths, and duplicate task IDs across projects.
