# Project Manager Insights 0.2.3

[English](./0.2.3.md)

Project Manager Insights 0.2.3 使用限定目录的增量目录索引替代重复的全 Vault 枚举，使 Project Manager 数据可以被缓存并按变化增量更新。

## 版本亮点

### Project Manager 增量目录索引

- 仅在 Project Manager 配置的项目目录中发现项目和任务，不再枚举 Vault 中的全部 Markdown 文件。
- 缓存标准化后的 Project Manager 快照，重复读取仪表盘时不再重复发现文件或查询元数据。
- 当受管项目或任务被创建、修改、重命名或删除时，仅增量更新对应目录记录。
- 忽略无关笔记的变化，不再因此触发 Project Manager 数据扫描或仪表盘刷新。
- 保留显式刷新能力；用户手动刷新时会根据 Project Manager 配置目录完整校准一次目录索引。

### 可靠性与兼容性

- 重放首次构建目录索引期间发生的相关文件事件，避免初始化竞争导致数据过期。
- 后续校准失败时继续保留最近一次有效快照。
- 保持现有项目、任务、优先级、完成状态、筛选、排序和工作量计算行为不变。
- 继续读取 Project Manager 的公开笔记元数据与项目目录配置，不依赖其私有运行时状态。

## 实测效果

以下数据来自本次发布验证使用的 Vault，其中共有 416 个 Markdown 文件和 262 条 Project Manager 记录（5 个项目、257 个任务）。实际效果会随 Vault 大小与目录结构而变化。

- 冷启动候选元数据查询从 416 次降至 262 次，减少 37%。
- 仪表盘缓存读取的元数据查询从 416 次降至 0 次。
- 单条 Project Manager 笔记变化由扫描 416 个文件降为更新 1 条记录，候选处理量减少 99.8%。
- 无关笔记发生元数据变化时，Project Manager 目录刷新次数为 0。
- 连续 30 次缓存读取均未触发全 Vault 枚举或元数据查询。

## 兼容与升级说明

- 继续支持 Obsidian `1.7.2` 或更高版本。
- 仍需要安装 Project Manager。
- 不需要迁移设置或笔记数据。
- 项目和任务仍以 Project Manager 配置的项目目录作为发现范围，默认目录为 `Projects`。
- 插件 ID 继续保持为 `project-manager-insights`。
- Project Manager Insights 仍保持只读，不会修改项目或任务笔记。

- 全部 15 项自动化测试通过，覆盖目录缓存、增量更新、初始化事件重放、设置校准和限定目录数据源行为。

本版本不会对 Project Manager 数据或已有 Project Manager Insights 设置造成破坏性变更。
