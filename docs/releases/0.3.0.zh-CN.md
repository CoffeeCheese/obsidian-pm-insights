# Project Manager Insights 0.3.0

[English](./0.3.0.md)

Project Manager Insights 0.3.0 新增基于所选项目完整任务树的交付进度跟踪，并提供引导式标签映射和结合验收条件的完成信号。

## 版本亮点

### 从任务树观察交付进度

- 独立于成员与任务抽屉筛选，分别查看设计、开发、测试、验收和加权总进度。
- 通过可配置的 Project Manager 任务标签归类设计、开发和测试叶子任务；层级映射如 `type/dev` 会同时匹配 `type/dev/frontend`。
- 验收由主任务推导：仅当主任务及所有被要求的前置阶段都已完成时，才计为已验收；面板会单独展示已满足前置条件、等待验收的主任务。
- 可配置各阶段权重、验收前置条件，以及无匹配任务时是否跳过统计。设置会阻止冲突的标签层级，并要求权重合计为 100%。
- 可从 Project Manager 已使用的标签中选择映射，查看标签被任务使用的次数和冲突提示；手动输入的标签也会保留。
- 提示交付数据质量问题，包括未分类或类型冲突的标签、未关联主任务的任务、缺失验收前置，以及提前完成的主任务。

### 更顺畅的导航与设置入口

- 无论 Project Manager 当前使用看板、表格还是甘特视图，均可从 PM Insights 打开任务。
- 可直接从仪表盘页头进入 PM Insights 设置。

## 兼容与升级说明

- 继续支持 Obsidian `1.7.2` 或更高版本。
- 仍需要安装 Project Manager；直接打开任务编辑器继续支持 Project Manager `1.8.x`。
- 已有安装会自动获得默认的交付进度配置，不需要迁移笔记或手动迁移设置。
- 插件 ID 继续保持为 `project-manager-insights`。
- Project Manager Insights 仍保持只读，不会修改项目或任务笔记。
