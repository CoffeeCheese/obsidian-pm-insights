# Project Manager Insights 0.2.2

[English](./0.2.2.md)

Project Manager Insights 0.2.2 新增 Project Manager 优先级分析与父任务统计模式，并针对窄面板和样式覆盖较强的 Obsidian 主题优化了成员任务表格。

## 版本亮点

### 优先级元数据、筛选与排序

- 直接读取 Project Manager 设置中的优先级定义，包括名称与颜色。
- 无法读取 Project Manager 设置时，继续使用内置优先级定义作为兼容回退。
- 在成员任务表格中新增优先级列。
- 支持按一个或多个优先级筛选任务，同时兼容无优先级任务和未知的自定义优先级值。
- 支持优先级从高到低、从低到高排序，并可恢复任务原始顺序。
- 排序表头与相邻表头保持一致，使用紧凑图标、键盘可访问文案、克制的下划线悬停反馈，并支持减少动态效果设置。

### 父任务统计模式

- 在 **包含已归档** 旁新增可持久化的 **统计父任务** 开关。
- 默认继续使用现有的子任务统计口径。
- 启用后，团队快照、成员卡片、交付比率、任务详情列表和数据质量摘要会统一切换为仅统计父任务。
- 同时支持根据 Project Manager 的显式 `type: task` 元数据和子任务 `parentId` 关系识别父任务。
- 父任务模式会排除子任务，避免父子任务的估算与工时被重复统计。

### 布局与交互优化

- 当 Obsidian 右侧边栏压缩可用空间时，任务筛选控件会继续保持在成员详情面板内部。
- 紧凑筛选布局改为根据详情容器宽度响应，而不是根据整个窗口宽度响应。
- 移除固定任务列旁过强的分隔线，同时保留横向滚动时的任务标题固定能力。
- 避免 Obsidian 主题把优先级排序表头渲染成凸起的正方形按钮或生成干扰视线的悬停提示。

## 兼容与升级说明

- 继续支持 Obsidian `1.7.2` 或更高版本。
- 仍需要安装 Project Manager。
- 不需要手动迁移设置；现有安装和新安装默认都不会启用父任务统计。
- 插件 ID 继续保持为 `project-manager-insights`。
- Project Manager Insights 仍保持只读，不会修改项目或任务笔记。
