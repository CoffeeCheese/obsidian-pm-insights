# Project Manager Insights 0.6.3

[English](./0.6.3.md)

Project Manager Insights 0.6.3 在成员任务列表中新增**完成时间**列，并优化个人交付简报的容量排版。

## 功能亮点

- 成员任务列表展示任务原生完成日期；有具体时刻时按设备本地时间显示，只有日期时保持日期格式，缺失或无效的值显示横线。该列与现有任务筛选和可调整列宽的表格一同使用。
- 阶段说明或负载状态较长时，容量节点文字不再重叠。日期与容量状态位于首行，阶段窗口说明独占下一行；累计负载和本窗口新增负载也能适应较窄卡片。

## 升级说明

无需迁移或新增设置。完成时间读取自 Project Manager 现有任务数据，插件不会修改任务笔记。本插件最低 Obsidian 版本仍为 1.7.2。

## 验证

- TypeScript 类型检查、Obsidian ESLint、官方审核检查、全部 215 项自动化测试及生产构建通过。
- 在 dev-test 库使用截图中的文字和更密集的内容，按三种卡片宽度检查了容量排版。发布前已将同源代码构建的插件安装并重载至 Obsd。
