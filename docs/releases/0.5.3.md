# Project Manager Insights 0.5.3

[简体中文](./0.5.3.zh-CN.md)

Project Manager Insights 0.5.3 adds a focused personal dashboard for each member, improves delivery-ledger language, and guides users when Project Manager or delivery-gate prerequisites are missing.

## Highlights

- Open a dedicated right-side personal-dashboard drawer from the gauge beside the selected member's name without expanding the main detail page.
- Read delivery health, a deadline-based personal runway, window progress, planned load, team comparison, work composition, and the all-time delivery ledger in one view.
- Choose a 7-, 14-, or 30-day load window, set a custom end date, and switch weekend inclusion at any time; capacity uses the configured workday or calendar-day hours.
- Select risk drivers, runway checkpoints, summary metrics, or project segments to close the drawer and filter the related source tasks.
- Compare personal results with a plain-language team reference derived from the middle sorted team value, averaging the middle pair for an even team, with clearer completion, time-against-plan, and planning-completeness labels.
- Show a member-specific delivery-gate reminder only when related projects are incomplete, explain which window metrics are affected, and open gate setup directly while keeping the delivery ledger available.
- Detect whether Project Manager is missing or disabled when PM Insights is opened and guide the user to its official Obsidian plugin page.

## Fixes

- Correct personal-dashboard membership, shared-task allocation, effective deadlines, all-time ledger ratios, team samples, and project mix so each view uses its intended statistical scope.
- Prevent theme-provided backgrounds from leaking horizontal grid lines into the drawer, and give each dashboard section a stable cross-theme surface.
- Keep the dashboard responsive and readable in narrower workspaces while preserving task-filter return context.

## Statistical notes

- The load window begins today. An effective deadline uses the task due date first, then the stage gate, then the project launch date.
- Planned load is unfinished estimated work due by the window end, including overdue commitments, divided by personal capacity. Shared effort is divided evenly among resolved assignees.
- Window progress includes non-cancelled, non-archived active tasks due by the window end; completed tasks enter the window only when their effective deadline is on or after today. The delivery ledger continues to use the member's complete active task history.
- Team references use the middle value after sorting available member results, averaging the middle pair for an even team; a missing valid sample is shown as unavailable instead of zero.

## Compatibility and upgrade notes

- Existing settings are normalized automatically with a 14-workday personal-dashboard default; no manual migration is required.
- Direct task-detail opening continues to support Project Manager `1.8.x` and `2.1.x`.
- Obsidian `1.7.2` or later remains supported.
- PM Insights remains read-only for Project Manager project and task notes.
