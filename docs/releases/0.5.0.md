# Project Manager Insights 0.5.0

[简体中文](./0.5.0.zh-CN.md)

Project Manager Insights 0.5.0 turns delivery gates from a fixed list of dates into an auditable delay-planning workflow. Teams can preserve the original plan, evaluate and confirm a later delivery path, and let actual gate progress automatically settle the remaining delay without rewriting Project Manager data.

## Highlights

### Original plans and delay plans stay separate

- Keep the original gate dates intact while creating, reviewing, and confirming a separate delay plan.
- Allow only one pending delay assessment at a time. Save it for review and confirm it directly from its timeline entry, or skip the review step and confirm the current plan immediately.
- Record every assessment and revision, including reductions such as changing a ten-day delay to five days, together with its adjustment reason and timestamps.
- Withdraw an active delay item in place so its status remains auditable without adding another noisy timeline entry.
- Lock original dates after delay history exists. Clear all delay data before changing those dates; the shared project clock remains editable.

### Dynamic delay entry and automatic settlement

- Enter a forecast date or type the number of workdays or calendar days to delay; both values stay synchronized.
- Use the compact minus and plus controls to adjust a delay one day at a time and cascade the change through later gates.
- Automatically settle a gate against its actual pass date. If a five-day delay is forecast but the gate passes after three days, the plan reflects the two days recovered without manual input.
- Preserve actual pass, reopen, correction, and launch events so the current plan can be explained from its history.
- Cancel an unsaved assessment and return to the previous plan, with confirmation when edited input would be discarded.

### One project clock across every calculation

- Choose whether a project advances through weekends or uses workdays only.
- Apply the same clock to expected progress, remaining time, overdue time, task-to-gate comparisons, delay values, and downstream forecasts.
- Preserve existing schedules as calendar-day plans until the user explicitly enables workday-only calculation.
- Keep the weekend rule editable even when original dates are locked, and explain unsaved clock changes before delay editing continues.

### Clearer timelines and risk context

- Add lightweight delay markers beside affected nodes on the original-plan timeline without crowding date fields.
- Show original, delayed, and actual dates directly in delivery-risk stage rows, together with forecast delay and remaining time.
- Surface delay status in project and risk summaries while keeping detailed revisions inside the delay-plan view.
- Refine focus borders, action hierarchy, responsive layouts, and reduced-motion behavior across the larger gate editor.

### Fixes and documentation

- Display schedule progress gaps with `%` instead of the internal `pp` abbreviation in both English and Simplified Chinese.
- Improve destructive confirmation styling and distinguish cancel, save-assessment, confirm, withdraw, and clear-data actions.
- Add a static Project Manager workspace overview to the bilingual README documentation.

## Compatibility and upgrade notes

- Obsidian `1.7.2` or later remains supported.
- Project Manager remains required. Project Manager Insights stores gate schedules, delay revisions, and actual gate events in its own plugin settings and does not rewrite project notes, task notes, or Project Manager metadata.
- Existing gate schedules migrate automatically and retain their previous calendar-day behavior.
- Existing PM Insights settings remain compatible; this release introduces no breaking data changes.
- The plugin ID remains `project-manager-insights`.
